# Лия и Королевство девяти желаний

Готовый персональный сайт-книга к девятому дню рождения Лии. Не требует сборки, установки программ, API-ключей или сервера. Весь сайт находится в этой папке.

## Обновление к девятилетию

Возраст Лии исправлен на 9 лет: на обложке, в прологе, поздравлении и книге PDF. На игровом торте девять свечей. Девять желаний и глав — по числу лет именинницы. Добавлена «Почта тёплых слов», обновлены облака с котятами и озеро желаний. Дата праздника сохранена: 18 ноября 2026 года.

Для обновления существующего сайта замените всё содержимое репозитория файлами из этого архива, сохраняя папки. Удалять репозиторий не нужно. После публикации обновите страницу с Ctrl+F5.

## Как открыть на компьютере

Распакуйте ZIP полностью. Откройте index.html двойным щелчком. Не открывайте index.html прямо внутри ZIP: сначала извлеките ВСЕ файлы.

Для максимально стабильной работы сохранения прогресса и скачивания файлов используйте опубликованный сайт. При локальном открытии ограничения зависят от браузера.

## Публикация на GitHub Pages — пошагово

1. Распакуйте ZIP через «Извлечь всё».
2. Войдите в GitHub. Нажмите «+» → **New repository**.
3. Назовите репозиторий, например **liya-nine-wishes**. Для бесплатного GitHub Pages выберите **Public**, затем **Create repository**. Созданный сайт и его иллюстрации будут доступны по ссылке.
4. Нажмите **uploading an existing file**. Если репозиторий уже создан с README, используйте **Add file → Upload files**.
5. Откройте распакованную папку. Загрузите ВСЁ ЕЁ СОДЕРЖИМОЕ: **index.html, style.css, app.js, content.js, magic.js, magic.css, README.md, START-HERE.txt**, а также ЦЕЛИКОМ папки **assets** и **keepsakes**. Сохраняйте вложенность папок. Не загружайте сам ZIP и не помещайте файлы внутрь лишней общей папки: index.html должен лежать сразу в корне репозитория.
6. Перетащите файлы и обе папки в окно Upload files. Если браузер не принимает папки, используйте GitHub Desktop: **File → Clone repository**, скопируйте содержимое распакованного архива в локальную папку репозитория, затем **Commit to main → Push origin**. Это сохраняет все картинки и вложенные папки автоматически.
7. Для загрузки через браузер нажмите **Commit changes**. В корне репозитория должны быть видны index.html и папки assets, keepsakes.
8. Откройте **Settings → Pages**. В разделе **Build and deployment** выберите **Source: Deploy from a branch**.
9. Выберите ветку **main** и папку **/(root)**. Нажмите **Save**.
10. Подождите завершения публикации. Ссылка появится на этой же странице рядом с **Visit site**. Сайт может появиться не сразу: обычно через несколько минут.
11. Откройте ссылку и проверьте обложку, котиков и первую главу. Все пути относительные: сайт работает в подпапке любого репозитория.

В архиве меньше 100 файлов. Самый крупный файл — книга PDF; все файлы существенно меньше лимита 25 МБ для браузерной загрузки GitHub. При необходимости можно загрузить корневые файлы, затем папки assets и keepsakes отдельными действиями, сохранив их названия и вложенность.

## Если PDF или диплом открылись в новой вкладке

Некоторые мобильные браузеры открывают файл вместо прямой загрузки. Нажмите «Поделиться» → «Сохранить в Файлы» (iPhone) или меню браузера → «Скачать» (Android). Эти же готовые файлы лежат в папке keepsakes и открываются отдельно без сайта.

## Как работают данные

Прогресс хранится только в localStorage браузера. На другом устройстве или в другом браузере прохождение начинается заново. Очистка данных браузера удалит прогресс. Новое прохождение запускается кнопкой «Начать сначала» с подтверждением. Повтор отдельной игры не удаляет уже полученную звезду.

Нет регистрации, форм с персональными данными, аналитики и рекламных трекеров. Тайное желание не вводится и не записывается. Все изображения, шрифты, музыка и файлы на память локальные. Нужные материалы не подгружаются с внешних сервисов.

## Что можно изменить

- Тексты глав, пожелания и поздравление: **content.js**.
- Игры, навигация, реплики котика, три истории и текст сюрприза: **app.js** и **magic.js**.
- Цвета, размеры и оформление: **style.css** и **magic.css**.
- Иллюстрации и звук: **assets/**.
- Сувениры: **keepsakes/**. PDF и диплом — готовые отдельные файлы; изменение текста сайта не меняет их автоматически.

При замене иллюстраций сохраняйте названия файлов и регистр. Если вносите изменения в текст поздравления, проверьте также PDF.

## Материалы

Иллюстрации созданы специально для этого проекта с помощью ImageGen. Музыка оригинальная, сгенерирована локальным синтезом; сторонние аудиозаписи не используются. Шрифты DejaVu включены локально; условия использования находятся в assets/FONT-LICENSE.txt.

## Версия «Девять желаний»

Восьмая глава — «Почта тёплых слов»: выбор котика, оформление, пожелание и анимация доставки открытки. Девятая — «Замок девятой звезды». В облачной долине появились объёмные облака и раскрытие котят; у озера — сияющая звезда, лунная дорожка и полёт желания.

Прогресс прежней версии автоматически переносится на том же устройстве и по тому же адресу: прежний замок становится девятой главой, новая почта остаётся доступна для прохождения после озера. Смена адреса сайта не переносит данные браузера.

Открытки доставляются сказочным котикам внутри игры. Письма не отправляются реальным людям.
